# BrainGame

Multiplayer Schulte table challenge. Players find 1 to 25 in order in 25 seconds, all at the same time. The host screen shows a live leaderboard and the winner.

- Host: open the site with `?host=1` on the projector laptop and create a room.
- Players: scan the QR code, enter a name, and wait for the host to start.
- Backend: Supabase (tables prefixed `st_`, see `schema.sql`).
